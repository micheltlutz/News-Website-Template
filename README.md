## Notícias Mobile

Template HTML do portal [Notícias Mobile](https://www.noticiasmobile.com.br), baseado em [Bootstrap](http://getbootstrap.com/) 4. Totalmente responsivo e fácil de customizar — ideal para blog, revista, portal de notícias, editorial ou site de reviews.
